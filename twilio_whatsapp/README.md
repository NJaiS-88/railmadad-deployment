# 💬 RailMadad Twilio WhatsApp Complaint Intake Agent

AI-powered Twilio WhatsApp bot for Indian Railways passenger grievance registration.

---

## 🌟 Key Features
1. **Interactive Conversational Intake**:
   - Collects **Registered Mobile Number**, **Train Number**, **Coach Number**, **10-Digit PNR**, and **Issue Description**.
   - Enforces a mandatory **"Is there anything else you would like to add?"** check before finalizing.
2. **MongoDB Database Account Linking**:
   - Automatically links the complaint to the passenger's registered Rail Madad account by mobile number.
   - Generates official `RMDA...` Complaint IDs.
3. **Asynchronous AI Triage Analysis**:
   - Runs OpenRouter AI triage models (`meta-llama/llama-3.1-8b-instruct`) to generate AI decision reasoning, category, and severity assessment.
4. **Rich WhatsApp Formatting**:
   - Returns structured WhatsApp messages formatted with bold, emojis, and code blocks for Complaint IDs.

## 🚀 Quick Start

### 1. Environment Setup
Ensure `.env` in the project root contains:
```env
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_auth_token_here
OPENROUTER_API_KEY=sk-or-your-key-here
TWILIO_WHATSAPP_PORT=6001
BACKEND_API_URL=http://127.0.0.1:5000/api
ML_SERVICE_URL=http://127.0.0.1:8000
```

### 2. Start the WhatsApp Server
```bash
cd twilio_whatsapp
python server.py
```
The server runs on **port 6001**.

### 3. Expose Port 6001 via Ngrok
```bash
ngrok http 6001
```
Copy the HTTPS URL generated by Ngrok (e.g. `https://your-ngrok-domain.ngrok-free.app`).

### 4. Configure Twilio WhatsApp Sandbox
1. Go to **Twilio Console** → **Messaging** → **Try it out** → **Send a WhatsApp message**.
2. Go to **Sandbox Settings**.
3. Under **"WHEN A MESSAGE COMES IN"**, set the URL to:
   ```
   https://your-ngrok-domain.ngrok-free.app/whatsapp/incoming
   ```
   Method: **HTTP POST**.
4. Click **Save**.

## 🧪 Testing

1. Send `"Hi"` to your Twilio WhatsApp Sandbox number (e.g. `+1 415 523 8886`).
2. Follow the interactive steps:
   - Provide Registered Mobile Number (`9372680382`)
   - Provide Train Number (`12019`)
   - Provide Coach Number (`A1`)
   - Provide PNR Number (`1234567890`)
   - Provide Issue Description (`Cleanliness issue in washroom`)
   - Answer the *"anything else to add"* prompt
3. Receive your official **Complaint ID (`RMDA...`)** directly on WhatsApp!
4. Open the RailMadad Web App frontend to view your linked complaint with full AI Triage reasoning!
